# Portofolio Pribadi — Syafira Issauma Dwi Andisa

Selamat datang di repositori portofolio pribadi **Syafira Issauma Dwi Andisa**, mahasiswa Sistem Informasi semester 5 dengan minat dan fokus mendalam pada bidang **UI/UX Design**.

Website ini dirancang dengan pendekatan modern, clean, minimalis, dan profesional dengan palet warna *off-white*, hijau segar (*fresh emerald green*), dan aksen gelap (*slate charcoal*).

---

## 🌿 Fitur Utama & Struktur Halaman

1. **Sticky Navbar**: Dilengkapi glassmorphism, navigasi smooth-scroll, tombol *"Let's Talk"*, dan mobile hamburger drawer.
2. **Hero Showcase**: Headline personal, status badge *"Available for collaboration"*, CTA ganda (*Lihat Project* & *Download CV*), serta profile card interaktif.
3. **About Me**: Narasi personal yang menghubungkan logika Sistem Informasi dengan empati UI/UX, kartu highlight, statistik semester & fokus, serta filosofi desain.
4. **Skills & Tools Matrix**: Dikelompokkan ke dalam 4 pilar (UI/UX Design, Design Tools, Development, Information Systems) dengan indikator kemahiran autentik.
5. **Selected Projects & Interactive Case Studies**:
   - **NGOPI.IN** — Food & Beverage Ordering Platform (Figma, React, UI/UX Design).
   - **Digital Library** — Academic Book Management System (Figma, IA, UI/UX Design).
   - **EduTrack LMS** — Student Learning & Progress Tracker (Figma, System Analysis).
   - *Interactive Case Study Modal* untuk melihat latar belakang masalah, solusi, dan proses perancangan.
6. **How I Design (Design Process)**: 5 tahapan terstruktur (*01 Research &rarr; 02 Define &rarr; 03 Ideate &rarr; 04 Design &rarr; 05 Test*).
7. **Experience & Activities**: Tab switcher interaktif untuk membedakan kategori *Organisasi*, *Kepanitiaan*, *Project Akademik*, *Pengalaman Kerja/Magang*, dan *Workshop*.
8. **Achievements**: Kartu penghargaan dan sertifikasi akademik.
9. **Contact ("Let's Work Together")**: Saluran kontak langsung (Email, LinkedIn, GitHub, Instagram), fitur salin email instan, serta formulir pesan dengan validasi dan *toast notification*.
10. **Footer**: Hak cipta, credits, dan tombol kembali ke atas.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur semantik, aksesibilitas, dan SEO-friendly.
- **Vanilla CSS3**: CSS Custom Properties (Variables), Flexbox & Grid, Glassmorphism backdrop-blur, transisi halus & micro-interactions.
- **JavaScript (ES6+)**: Logika filter kategori project, modal popup studi kasus, tab navigasi pengalaman, toast notification, dan interaksi clipboard.
- **Google Fonts**: Plus Jakarta Sans & Space Grotesk.

---

## 🚀 Cara Menjalankan Secara Lokal

Website ini dibangun murni di sisi browser tanpa dependensi runtime atau build tools:

1. Clone repositori ini:
   ```bash
   git clone https://github.com/syafiraissauma/syafira-antigravity.git
   ```
2. Buka folder proyek dan jalankan `index.html` langsung di browser Anda, atau gunakan live server:
   ```bash
   python -m http.server 8080
   ```
3. Akses melalui `http://localhost:8080` di browser.
